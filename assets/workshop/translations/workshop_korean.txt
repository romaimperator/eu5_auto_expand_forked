[h1]주요 기능[/h1]
[h2]RGO 자동 확장[/h2]
RGO(자원 생산지) 자동 확장 기능을 추가합니다! 두 곳에서 활성화할 수 있습니다. 첫째는 현재 RGO를 확장할 수 있는 개별 지역 보기 화면이고, 둘째는 일괄 RGO 확장 도구 화면입니다.

다음 조건 충족 시 자동으로 확장됩니다:
[list]
 [*]RGO가 최대 레벨이 아님
 [*]RGO가 풀 고용 상태이거나 한 달간의 승급(promotion) 후 풀 고용이 될 예정임
 [*]국가가 최소 100 두캇(1단계 생산 건물 비용과 동일) 및 설정된 최소 보유 골드 이상을 보유함
 [*]해당 RGO 레벨이 이미 건설 중이지 않음
[/list]

[h3]RGO 일괄 자동 확장[/h3]
RGO 건설 도구 화면에서 RGO 자동 확장을 활성화하거나 비활성화할 수 있는 버튼이 있습니다. 필터를 적용한 상태에서 일괄 자동 확장 버튼을 클릭하면 해당 필터가 적용된 지역들에만 영향을 줍니다.

[h2]건물 자동 확장[/h2]
특정 건물을 설정하여 매달 다음과 같은 조건 충족 시 자동으로 확장 및 추가 레벨을 건설하도록 합니다:
[list]
 [*]수익성이 있음 (상품을 생산하지 않는 건물 제외)
 [*]부족한 물자가 없음
 [*]풀 고용 상태임
 [*]승급 가능한 팝(Pop)이 충분히 존재함
[/list]
자동 확장 버튼은 생산 탭을 통해 들어가는 전체 건설 메뉴나, 지역 보기 화면에서 다양한 팝 유형을 클릭하여 들어가는 지역 기반 건설 메뉴에서 찾을 수 있습니다.

[h3]툴팁[/h3]
툴팁은 건물이 자동으로 확장되거나, 자동 업그레이드되거나, 혹은 아무 작업도 하지 않는 이유를 보여줍니다. 또한 해당 건물을 자동 확장하기 위해 필요한 두캇이 얼마인지도 보여줍니다. 여기에는 구성된 최소 비용과 건물의 예상 건설 비용이 포함됩니다.

[h3]자동 업그레이드[/h3]
건물이 구식이고 업그레이드가 해제된 경우, 자동 확장과 동일한 규칙에 따라 건물이 자동으로 업그레이드됩니다. 기본적으로 활성화되어 있으며, 설정 창에서 비활성화할 수 있습니다.

[h3]건물 일괄 자동 확장[/h3]
특정 건물 유형의 건설 도구 화면에서 건물 자동 확장을 활성화하거나 비활성화할 수 있는 버튼이 있습니다. 필터를 적용한 상태에서 일괄 자동 확장 버튼을 클릭하면 해당 필터가 적용된 지역들에만 영향을 줍니다.

[h2]지역당 1개 제한 건물의 자동 건설[/h2]
지역당 하나만 건설 가능한 건물(사원, 도서관 등)을 요구 사항을 충족하고 골드가 충분할 때 모든 지역에 자동으로 건설하도록 설정하는 기능을 추가합니다. 또한, 각 건물 유형에 대해 종속국에서의 자동 건설 여부를 활성화/비활성화할 수 있습니다.

[b][u]최소 통제도(Control):[/u][/b] 각 건물 유형을 자동 건설하기 위해 지역에 필요한 최소 통제도를 설정할 수 있습니다. 기본값은 최대 통제도를 늘려주는 사원과 조폐국(0%), 인구 성장을 늘려주는 정착지(0%)를 제외한 모든 유형에서 50%입니다.

[b][u]최소 시장 가격 영향(Market Price Impact):[/u][/b] 각 건물 유형을 자동 건설하기 위해 지역에 필요한 최소 시장 가격 영향을 설정할 수 있습니다. 기본값은 최대 할인치인 -33%입니다. 시장 가격 영향은 건물의 건설 자재 현재 가격에 따른 할인(또는 인상) 폭을 의미합니다. 설정 창에서 건물 유형 위에 마우스를 올리면 해당 지역의 현재 시장 가격 영향을 확인할 수 있습니다.

[b][u]우선순위:[/u][/b] 어떤 건물을 먼저 자동 건설할지에 대한 우선순위는 설정 창에서 건물 유형 왼쪽에 있는 위아래 화살표 버튼을 클릭하여 조정할 수 있습니다. Shift+클릭 시 해당 건물 유형을 리스트의 맨 위나 맨 아래로 이동시킵니다.

체크박스를 우클릭하면 모든 건물 유형의 자동 건설을 토글합니다. 종속국 체크박스를 우클릭하면 모든 건물 유형의 종속국 자동 건설을 토글합니다.

여기에는 제동소(sawmills), 풍차(windmills), 지역 제련소(local smelters)가 포함되며, 지역에 충분한 RGO 레벨(제동소의 경우 목재소)이 있는 경우 자동 건설됩니다. 이 수치는 기본적으로 5레벨이며 설정 창에서 변경 가능합니다.

지역당 1개 제한 건물 외에도, 각 지역에 시장 마을(market villages) 1단계를 자동 건설하도록 설정할 수 있습니다.

건물 유형 위에 마우스를 올리면 해당 건물을 지원하는 지역 목록과 해당 지역에서 자동 건설이 가능한지 여부가 표시됩니다. 각 지역 위에 마우스를 올리면 자동 건설이 가능하거나 불가능한 이유를 확인할 수 있습니다.

[h2]추가 필터[/h2]
[list]
 [*]RGO가 최소 X 이상의 식량 가치를 생산하는 지역 필터 (X는 슬라이더로 조절)
 [*]RGO 자동 확장이 활성화된 지역과 비활성화된 지역을 구분하는 필터
 [*]자동 확장이 활성화된 지역이 하나라도 있는 건물을 건물 목록에서 필터링 (생산 패널의 건물 탭 목록)
 [*]자동 확장이 비활성화된 지역이 하나라도 있는 건물을 건물 목록에서 필터링
[/list]

[h2]설정[/h2]
아무 자동 확장 버튼이나 우클릭하여 설정 창을 열 수 있습니다. 여기에서 다음을 수행할 수 있습니다:
[list]
 [*]모든 자동 확장 일시정지/해제 (기본값: 꺼짐)
 [*]건물 자동 업그레이드 활성화/비활성화 (기본값: 켜짐)
 [*]보유해야 할 최소 골드량 조정
 [*]지역에서 자동 확장이 중단되기 전까지 소프트 캡(지원되는 건물 레벨)을 초과하여 건설할 레벨 수 조정
 [*]지역당 1개 제한 건물의 자동 건설 활성화/비활성화
 [*]먼저 자동 건설될 건물의 우선순위 조정
 [*]건물 유형별 자동 건설에 필요한 최소 통제도 조정
 [*]건물 유형별 자동 건설에 필요한 최소 시장 가격 영향 조정
 [*]제동소, 풍차, 지역 제련소를 자동 건설하는 데 필요한 RGO 또는 목재소의 수 조정
 [*]자동 건설 우선순위를 기본값으로 초기화
[/list]
