[h1]기능[/h1]
[h2]RGO 자동 확장[/h2]
RGO 자동 확장 기능을 추가합니다! 두 곳에서 활성화할 수 있습니다. 첫째, 현재 RGO를 확장할 수 있는 개별 지역 뷰. 둘째, 대량 RGO 확장기 뷰.

다음 조건에서 자동 확장됩니다:
[list]
 [*]RGO가 최대 레벨이 아님
 [*]RGO 고용이 가득 찼거나 한 달 치의 승급 후 가득 찰 예정임
 [*]국가가 최소 100 두카트(1단계 생산 건물과 동일)와 유지할 최소 골드 금액을 보유함
 [*]이미 건설 중인 RGO 레벨이 없음
[/list]

[h3]RGO 대량 자동 확장[/h3]
RGO 빌더 뷰에서 RGO 자동 확장을 활성화하거나 비활성화할 수 있는 버튼이 있습니다. 적용한 모든 필터는 대량 자동 확장 버튼을 클릭할 때 영향을 받는 지역에도 필터링되어 적용됩니다.

[h2]건물 자동 확장[/h2]
특정 건물이 다음과 같은 경우 매달 틱마다 자동으로 확장 및 추가 레벨을 건설하도록 설정하는 기능을 추가합니다:
[list]
 [*]수익성이 있음 (상품을 생산하지 않는 건물 제외)
 [*]부족한 상품이 없음
 [*]고용이 가득 참
 [*]충분한 승급된 팝이 있음
[/list]
자동 확장 버튼은 생산 탭을 통해 접속하는 글로벌 건설 메뉴 또는 지역 뷰에서 다른 팝 유형을 클릭하여 접속하는 로컬 지역 기반 건설 메뉴에서 찾을 수 있습니다.

[h3]툴팁[/h3]
툴팁에는 건물이 왜 자동 확장되거나, 자동 업그레이드되는지, 혹은 둘 다 되지 않는지에 대한 이유가 표시됩니다. 또한 해당 건물을 자동 확장하기 전까지 필요한 두카트 양도 보여줍니다. 여기에는 설정된 최소 금액과 건물의 예상 비용이 포함됩니다.

[h3]자동 업그레이드[/h3]
건물이 구식이고 업그레이드를 해제한 경우, 확장과 동일한 규칙에 따라 건물이 자동으로 업그레이드됩니다. 기본적으로 활성화되어 있지만, 설정 창에서 비활성화할 수 있습니다.

[h3]건물 대량 자동 확장[/h3]
특정 건물 유형 빌더 뷰에서 건물 자동 확장을 활성화하거나 비활성화할 수 있는 버튼이 있습니다. 적용한 모든 필터는 대량 자동 확장 버튼을 클릭할 때 영향을 받는 지역에도 필터링되어 적용됩니다.

[h2]지역당 1개 제한 건물 자동 건설[/h2]
특정 지역당 1개 제한 건물(사원, 도서관 등)을 요구 사항을 충족하고 골드가 충분할 때 모든 지역에 자동으로 건설하는 기능을 추가합니다. 또한, 각 건물 유형에 대해 종속국의 자동 건설 여부를 활성화/비활성화할 수 있습니다.

[b][u]최소 통제력:[/u][/b] 각 건물 유형을 자동 건설하기 전에 지역에 필요한 최소 통제력 수치를 구성할 수 있습니다. 기본값은 모든 유형에 대해 50%이며, 사원과 조폐국은 최대 통제력을 추가하고 정착지는 인구 성장을 추가하므로 기본값이 0%입니다.

[b][u]최소 시장 가격 영향력:[/u][/b] 각 건물 유형을 자동 건설하기 전에 지역에 필요한 최소 시장 가격 영향력을 구성할 수 있습니다. 기본값은 최대 할인율인 -33%입니다. 시장 가격 영향력은 건물의 건설 자재 현재 비용에서 할인(또는 증가)되는 가격입니다. 설정 창에서 건물 유형 위에 마우스를 올리면 해당 지역의 현재 시장 가격 영향력이 표시됩니다.

[b][u]우선순위:[/u][/b] 어떤 건물을 먼저 자동 건설할지에 대한 우선순위는 설정 창에서 건물 유형 왼쪽에 있는 위아래 화살표 버튼을 클릭하여 조정할 수 있습니다. Shift+클릭 시 해당 건물 유형이 목록의 맨 위나 맨 아래로 이동합니다.

체크박스를 우클릭하면 모든 건물 유형의 자동 건설이 토글됩니다. 종속국 체크박스를 우클릭하면 종속국의 모든 건물 유형 자동 건설이 토글됩니다.

여기에는 제재소, 풍차, 로컬 제련소가 포함되며, 지역에 충분한 RGO 레벨(제재소의 경우 벌목 캠프)이 있는 경우 자동으로 건설됩니다. 이 숫자는 기본적으로 5레벨이며 설정 창에서 구성 가능합니다.

지역당 1개 제한 건물 외에도, 각 지역에 시장 마을 1레벨 자동 건설을 활성화할 수 있습니다.

건물 유형 위에 마우스를 올리면 해당 건물 유형을 지원하는 지역 목록이 표시되며, 해당 지역에서 자동 건설이 가능한지 여부가 나타납니다. 각 지역 위에 마우스를 올리면 자동 건설이 가능하거나 불가능한 이유를 확인할 수 있습니다.

[h2]추가 필터[/h2]
[list]
 [*]RGO가 최소 X 이상의 식량 가치를 생산하는 지역 필터 (X는 슬라이더로 조절)
 [*]RGO 자동 확장이 활성화된 지역과 비활성화된 지역 필터
 [*]자동 확장이 활성화된 지역이 최소 1개 이상인 건물 목록 필터 (생산 패널의 건물 탭 목록)
 [*]자동 확장이 비활성화된 지역이 최소 1개 이상인 건물 목록 필터
[/list]
