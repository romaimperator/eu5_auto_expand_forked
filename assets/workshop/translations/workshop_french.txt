[h1]Fonctionnalités[/h1]
[h2]Extension automatique des RGO[/h2]
Ajoute l'extension automatique pour les RGO ! Vous pouvez l'activer à deux endroits. Premièrement, dans la vue d'un lieu individuel où vous pouvez actuellement étendre un RGO. Deuxièmement, dans la vue de l'extenseur de RGO de masse.

L'extension automatique se produira si :
[list]
 [*]le RGO n'est pas au niveau maximum
 [*]le RGO est à pleine capacité d'emploi ou le sera après un mois de promotions
 [*]le pays possède au moins 100 ducats (identique aux bâtiments de production de premier niveau) plus le montant minimum d'or à conserver.
 [*]aucun niveau de RGO n'est déjà en cours de construction
[/list]

[h3]Extension automatique de masse pour les RGO[/h3]
Il existe un bouton pour activer ou désactiver l'extension automatique des RGO que vous pouvez trouver dans la vue du constructeur de RGO. Tous les filtres que vous appliquez filtreront également les lieux affectés lorsque vous cliquerez sur le bouton d'extension automatique de masse.

[h2]Extension automatique des bâtiments[/h2]
Ajoute la possibilité de configurer des bâtiments spécifiques pour qu'ils s'étendent et construisent des niveaux supplémentaires automatiquement à chaque tick mensuel s'ils sont :
[list]
 [*]rentables (sauf s'ils ne produisent pas de marchandises)
 [*]ne manquent d'aucune marchandise
 [*]pleinement employés
 [*]il y a suffisamment de populations (pops) promues disponibles
[/list]
Le bouton d'extension automatique se trouve soit dans le menu de construction global accessible par l'onglet de production, soit dans le menu de construction local basé sur le lieu, accessible en cliquant sur les différents types de populations dans la vue du lieu.

[h3]Infobulle[/h3]
L'infobulle indique pourquoi le bâtiment va s'étendre automatiquement, s'améliorer automatiquement ou ne rien faire. Elle vous indique également combien de ducats sont nécessaires avant l'extension automatique de ce bâtiment. Cela inclut le minimum configuré ainsi qu'un coût estimé du bâtiment.

[h3]Amélioration automatique[/h3]
Les bâtiments seront automatiquement améliorés selon les mêmes règles que l'extension si le bâtiment est également obsolète et que vous avez débloqué l'amélioration. Bien qu'activée par défaut, vous pouvez désactiver cette option dans la fenêtre des paramètres.

[h3]Extension automatique de masse pour les bâtiments[/h3]
Il existe un bouton pour activer ou désactiver l'extension automatique des bâtiments que vous pouvez trouver dans la vue du constructeur par type de bâtiment spécifique. Tous les filtres que vous appliquez filtreront également les lieux affectés lorsque vous cliquerez sur le bouton d'extension automatique de masse.

[h2]Construction automatique pour les bâtiments uniques par lieu[/h2]
Ajoute la possibilité de configurer certains bâtiments uniques par lieu (temple, bibliothèque, etc.) pour qu'ils se construisent automatiquement dans chaque lieu qui remplit les conditions et lorsque suffisamment d'or est disponible. De plus, vous pouvez activer/désactiver la construction automatique de ces bâtiments chez les sujets pour chaque type de bâtiment.

[b][u]Contrôle minimum :[/u][/b] Vous pouvez configurer le montant minimum de contrôle requis dans un lieu avant la construction automatique de chaque type de bâtiment. Par défaut, ce montant est de 50 % pour tous les types, sauf pour les temples et les bureaux de frappe de monnaie (0 % car ils ajoutent du contrôle max) et les établissements (car ils ajoutent de la croissance démographique).

[b][u]Impact minimum sur le prix du marché :[/u][/b] Vous pouvez configurer l'impact minimum sur le prix du marché requis dans un lieu avant la construction automatique de chaque type de bâtiment. Par défaut, il s'agit de la réduction maximale de -33 %. L'impact sur le prix du marché est la réduction (ou l'augmentation) du prix par rapport au coût actuel des matériaux de construction du bâtiment. Survoler n'importe quel type de bâtiment dans la fenêtre des paramètres vous montrera l'impact actuel sur le prix du marché du lieu.

[b][u]Priorité :[/u][/b] La priorité des bâtiments à construire automatiquement en premier peut être ajustée dans la fenêtre des paramètres en cliquant sur les flèches haut et bas à gauche du type de bâtiment. Shift+clic sur la flèche vers le haut déplacera le type de bâtiment en haut de la liste. Shift+clic sur la flèche vers le bas déplacera le type de bâtiment en bas de la liste.

Un clic droit sur la case à cocher basculera la construction automatique pour tous les types de bâtiments. Un clic droit sur la case à cocher des sujets basculera la construction automatique pour tous les types de bâtiments chez les sujets.

Cela inclut les scieries, les moulins à vent et les fonderies locales qui seront construits automatiquement si le lieu a assez de niveaux de RGO (ou de camps de bûcherons dans le cas des scieries). Ce nombre est par défaut de 5 niveaux et est configurable dans la fenêtre des paramètres.

En plus des bâtiments uniques par lieu, vous pouvez activer la construction automatique d'un niveau de villages de marché dans chaque lieu.

Survoler le type de bâtiment affichera la liste des lieux qui supportent ce type de bâtiment et indiquera si le bâtiment peut être construit automatiquement dans ce lieu. Vous pouvez survoler chaque lieu pour voir les raisons pour lesquelles il peut ou ne peut pas être construit automatiquement.

[h2]Filtres additionnels[/h2]
[list]
 [*]filtre pour les lieux dont le RGO produit au moins X valeur de nourriture, où X est un curseur (comme le curseur de contrôle)
 [*]filtre pour les lieux ayant l'extension automatique de RGO activée et un autre pour l'extension automatique désactivée
 [*]filtre sur la liste des bâtiments pour les bâtiments ayant au moins 1 lieu avec l'extension automatique activée (il s'agit de la liste qui s'affiche lorsque vous cliquez sur le panneau de production et que vous êtes sur l'onglet des bâtiments)
 [*]filtre sur la liste des bâtiments pour les bâtiments ayant au moins 1 lieu avec l'extension automatique désactivée
[/list]

[h2]Paramètres[/h2]
Accédez à la fenêtre des paramètres en faisant un clic droit sur n'importe quel bouton d'extension automatique. Ici, vous pouvez :
[list]
 [*]suspendre/reprendre toutes les extensions automatiques (désactivé par défaut)
 [*]activer/désactiver l'amélioration automatique des bâtiments (activé par défaut)
 [*]ajuster les montants minimums d'or
 [*]ajuster le nombre de niveaux au-dessus du "soft cap" (niveaux de bâtiments supportés) avant que l'extension automatique ne s'arrête dans un lieu
 [*]activer/désactiver la construction automatique des bâtiments uniques par lieu
 [*]ajuster la priorité des bâtiments à construire en premier
 [*]ajuster le contrôle minimum requis dans un lieu avant la construction automatique de chaque type de bâtiment
 [*]ajuster l'impact minimum sur le prix du marché requis dans un lieu avant la construction automatique de chaque type de bâtiment
 [*]ajuster le nombre de RGO ou de camps de bûcherons requis pour construire automatiquement des scieries, des moulins à vent et des fonderies locales
 [*]réinitialiser la priorité de construction automatique par défaut
[/list]

[h1]Utiliser le mod avec le Patch 1.1 :[/h1]
Vous pouvez toujours utiliser l'ancienne version de ce mod avec le Patch 1.1 en la téléchargeant depuis la page des [url=https://steamcommunity.com/sharedfiles/filedetails/changelog/3659626562]notes de version (change notes)[/url] et en la plaçant dans votre dossier de mods local.

Pour ce faire, suivez ces étapes :
[olist]
 [*]Allez sur la page des [url=https://steamcommunity.com/sharedfiles/filedetails/changelog/3659626562]notes de version[/url] de ce mod.
 [*]Trouvez l'entrée "Update: Apr 5 @ 4:32pm" avec la description "Reverting because multiple reports of issues with 1.10.1" et cliquez sur le bouton "Download".
 [*]Une fois le téléchargement terminé, allez dans votre dossier de téléchargements, trouvez le nouveau fichier zip et décompressez-le.
 [*]Ensuite, allez dans Documents -> Paradox Interactive -> Europa Universalis V -> mod (si le dossier mod n'existe pas, créez-le).
 [*]Copiez le dossier décompressé dans ce dossier mod.
 [*]Lancez le jeu. Il devrait maintenant y avoir deux copies du mod listées dans le gestionnaire de mods.
 [*]Créez un nouvel ensemble de mods (playset) ou sélectionnez-en un existant, puis survolez chaque copie du mod pour trouver celle avec la version "1.10.0" et sélectionnez-la pour l'ajouter à l'ensemble.
 [*]Enfin, chargez cet ensemble avant de charger toute sauvegarde du Patch 1.1 avec laquelle vous souhaitez continuer à utiliser le mod. Sinon, vous pouvez continuer à utiliser votre ensemble existant avec la dernière version du mod.
[/olist]
