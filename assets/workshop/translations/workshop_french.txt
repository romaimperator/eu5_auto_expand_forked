Ce mod est entièrement compatible avec le patch 1.2.

[h1]Fonctionnalités[/h1]
[h2]Auto-extension pour les RGO[/h2]
Ajoute l'auto-extension pour les RGO ! Vous pouvez l'activer à deux endroits. Premièrement, dans la vue d'un lieu individuel où vous pouvez actuellement étendre un RGO. Deuxièmement, dans la vue de l'extendeur de RGO en masse.

Il s'étendra automatiquement si :
[list]
 [*]le RGO n'est pas au niveau maximum
 [*]le RGO est pleinement employé ou le sera après un mois de promotions
 [*]le pays possède au moins 100 ducats (identique aux bâtiments de production de premier niveau) plus le montant minimum d'or à conserver.
 [*]il n'y a pas déjà un niveau de RGO en cours de construction
[/list]

[h3]Auto-extension de masse pour les RGO[/h3]
Il existe un bouton pour activer ou désactiver l'auto-extension des RGO que vous pouvez trouver dans la vue du constructeur de RGO. Tous les filtres que vous appliquez filtreront également les lieux affectés lorsque vous cliquez sur le bouton d'auto-extension de masse.

[h2]Auto-extension pour les bâtiments[/h2]
Ajoute la possibilité de configurer des bâtiments spécifiques pour qu'ils s'étendent et construisent des niveaux supplémentaires automatiquement à chaque tick mensuel s'ils sont :
[list]
 [*]rentables (sauf s'ils ne produisent pas de biens)
 [*]ne manquent d'aucun bien
 [*]pleinement employés
 [*]il y a assez de pops promues disponibles
[/list]
Le bouton d'auto-extension se trouve soit dans le menu de construction global accessible par l'onglet de production, soit dans le menu de construction local basé sur le lieu accessible en cliquant sur les différents types de pops dans la vue du lieu.

[h3]Infobulle[/h3]
L'infobulle montre pourquoi le bâtiment va s'étendre automatiquement, s'améliorer automatiquement, ou ne fera ni l'un ni l'autre. Elle vous montre également combien de ducats sont nécessaires avant l'auto-extension de ce bâtiment. Cela inclut le minimum configuré ainsi qu'un coût estimé du bâtiment.

[h3]Amélioration automatique[/h3]
Les bâtiments seront améliorés automatiquement selon les mêmes règles que l'extension si le bâtiment est également obsolète et que vous avez débloqué l'amélioration. Bien qu'activée par défaut, vous pouvez désactiver cette option dans la fenêtre des paramètres.

[h3]Auto-extension de masse pour les bâtiments[/h3]
Il existe un bouton pour activer ou désactiver l'auto-extension des bâtiments que vous pouvez trouver dans la vue du constructeur par type de bâtiment spécifique. Tous les filtres que vous appliquez filtreront également les lieux affectés lorsque vous cliquez sur le bouton d'auto-extension de masse.

[h2]Auto-construction pour les bâtiments uniques par lieu[/h2]
Ajoute la possibilité de configurer des bâtiments spécifiques limités à un par lieu (temple, bibliothèque, etc.) pour qu'ils se construisent automatiquement dans chaque lieu qui remplit les conditions et lorsque suffisamment d'or est disponible. De plus, vous pouvez activer/désactiver l'auto-construction de ces bâtiments chez les sujets pour chaque type de bâtiment.

[b][u]Contrôle minimum :[/u][/b] Vous pouvez configurer le montant minimum de contrôle requis dans un lieu avant l'auto-construction de chaque type de bâtiment. Par défaut, ce seuil est de 50 % pour tous les types, sauf pour les temples et les bureaux de frappe qui sont à 0 % par défaut car ils ajoutent du contrôle max, ainsi que pour les colonies puisqu'elles ajoutent de la croissance démographique.

[b][u]Impact minimum sur le prix du marché :[/u][/b] Vous pouvez configurer l'impact minimum sur le prix du marché requis dans un lieu avant l'auto-construction de chaque type de bâtiment. Par défaut, il s'agit de la remise maximale de -33 %. L'impact sur le prix du marché est la remise (ou l'augmentation) du prix par rapport au coût actuel des matériaux de construction du bâtiment. Survoler n'importe quel type de bâtiment dans la fenêtre des paramètres vous montrera l'impact actuel du prix du marché du lieu.

[b][u]Priorité :[/u][/b] La priorité des bâtiments à construire automatiquement en premier peut être ajustée dans la fenêtre des paramètres en cliquant sur les boutons fléchés haut et bas à gauche du type de bâtiment. Shift+clic sur la flèche haut déplacera le type de bâtiment en haut de la liste. Shift+clic sur la flèche bas déplacera le type de bâtiment en bas de la liste.

Un clic droit sur la case à cocher basculera l'auto-construction pour tous les types de bâtiments. Un clic droit sur la case à cocher des sujets basculera l'auto-construction pour tous les types de bâtiments chez les sujets.

Cela inclut les scieries, les moulins à vent et les fonderies locales qui seront construits automatiquement si le lieu a assez de niveaux de RGO (ou de camps de bûcherons dans le cas des scieries). Ce nombre est par défaut de 5 niveaux et est configurable dans la fenêtre des paramètres.

En plus des bâtiments uniques par lieu, vous pouvez activer l'auto-construction d'un niveau de villages de marché dans chaque lieu.

Survoler le type de bâtiment affichera la liste des lieux qui supportent ce type de bâtiment et indiquera si le bâtiment peut y être construit automatiquement. Vous pouvez survoler chaque lieu pour voir les raisons pour lesquelles il peut ou ne peut pas être construit automatiquement.

[h2]Filtres additionnels[/h2]
[list]
 [*]filtre pour les lieux dont le RGO produit au moins une valeur X de nourriture, où X est un curseur (comme le curseur de contrôle)
 [*]filtre pour les lieux ayant l'auto-extension RGO activée et un autre pour l'auto-extension RGO désactivée
 [*]filtre sur la liste des bâtiments pour les bâtiments ayant au moins 1 lieu avec l'auto-extension activée (il s'agit de la liste qui s'affiche lorsque vous cliquez sur le panneau de production et que vous êtes sur l'onglet des bâtiments)
 [*]filtre sur la liste des bâtiments pour les bâtiments ayant au moins 1 lieu avec l'auto-extension désactivée
[/list]

[h2]Paramètres[/h2]
Accédez à la fenêtre des paramètres en faisant un clic droit sur n'importe quel bouton d'auto-extension. Ici, vous pouvez :
[list]
 [*]mettre en pause/reprendre toutes les auto-extensions (désactivé par défaut)
 [*]activer/désactiver l'amélioration automatique des bâtiments (activé par défaut)
 [*]ajuster les montants minimums d'or
 [*]ajuster le nombre de niveaux au-dessus du "soft cap" (niveaux de bâtiments supportés) avant que l'auto-extension ne s'arrête dans un lieu
 [*]activer/désactiver l'auto-construction des bâtiments uniques par lieu
 [*]ajuster la priorité des bâtiments à construire automatiquement en premier
 [*]ajuster le contrôle minimum requis dans un lieu avant l'auto-construction de chaque type de bâtiment
 [*]ajuster l'impact minimum sur le prix du marché requis dans un lieu avant l'auto-construction de chaque type de bâtiment
 [*]ajuster le nombre de RGO ou de camps de bûcherons requis pour construire automatiquement des scieries, des moulins à vent et des fonderies locales
 [*]réinitialiser la priorité d'auto-construction par défaut
[/list]

[h1]Utiliser le mod avec le Patch 1.1 :[/h1]
Vous pouvez toujours utiliser l'ancienne version de ce mod avec le Patch 1.1 en la téléchargeant depuis la page des [url=https://steamcommunity.com/sharedfiles/filedetails/changelog/3659626562]notes de changement[/url] et en la plaçant dans votre dossier de mods local.

Pour ce faire, suivez ces étapes :
[olist]
 [*]Allez sur la page des [url=https://steamcommunity.com/sharedfiles/filedetails/changelog/3659626562]notes de changement[/url] de ce mod.
 [*]Trouvez l'entrée pour "Update: Apr 5 @ 4:32pm" avec la description "Reverting because multiple reports of issues with 1.10.1" et cliquez sur le bouton "Download".
 [*]Une fois le téléchargement terminé, allez dans votre dossier de téléchargements, trouvez le nouveau fichier zip et décompressez-le.
 [*]Ensuite, allez dans Documents -> Paradox Interactive -> Europa Universalis V -> mod (si le dossier mod n'existe pas, créez-le).
 [*]Copiez le dossier décompressé dans ce dossier mod.
 [*]Lancez le jeu. Il devrait maintenant y avoir deux copies du mod listées dans le gestionnaire de mods.
 [*]Créez un nouvel ensemble de mods (ou sélectionnez-en un existant), puis survolez chaque copie du mod pour trouver celle avec la version "1.10.0" et sélectionnez-la pour l'ajouter à l'ensemble.
 [*]Enfin, chargez cet ensemble de mods avant de charger n'importe quelle sauvegarde du Patch 1.1 avec laquelle vous souhaitez continuer à utiliser le mod. Sinon, vous pouvez continuer à utiliser votre ensemble actuel avec la dernière version du mod.
[/olist]
